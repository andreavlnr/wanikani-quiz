# Kani Choice v4 – azonnal használható

Ez a verzió nem igényel npm installt vagy buildet. Több fájlra bontott, böngészőben közvetlenül futó JavaScript-modulokat használ.

## GitHub Pages frissítés

1. Nyisd meg a jelenlegi repositoryt.
2. Add file → Upload files.
3. Húzd be ennek a csomagnak az összes fájlját és a `src` mappát is.
4. Commit changes.
5. A GitHub Pages beállítása marad: main / root.

A kezdőképernyőn a Tananyagtípus menüben látható a „Csak vocabulary”, valamint a „Kanji és vocabulary” opció.
